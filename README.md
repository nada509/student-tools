# 🎓 Student Tools – Academic Productivity Platform

**Student Tools** is a free, responsive, and user-friendly web application designed to help university students manage their studies, organize their time, calculate academic results, and find inspiration for graduation projects.

The platform brings together a collection of simple and practical student-focused tools in one place, with support for **English and Arabic** and both **Light and Dark modes**.

## 🚀 Live Demo

Try the live application:

**https://nada509.github.io/student-tools/**

---

## ✨ Features

### 📊 Academic Tools

* **GPA Calculator** – Calculate GPA based on courses, credits, and grades.
* **Percentage Calculator** – Quickly calculate percentages for academic results and other calculations.
* **Study Time Calculator** – Calculate available and required study time based on your study schedule.

### ⏱️ Productivity Tools

* **Pomodoro Timer** – Use focused study sessions to improve concentration and productivity.
* **To-Do List** – Create and manage tasks to stay organized.

### 🎓 Graduation Project Ideas

* Browse a collection of graduation project ideas.
* Explore different project topics and technologies.
* Find inspiration for Computer Science, Artificial Intelligence, Software Engineering, and other technology-related projects.

### 🌐 User Experience

* English and Arabic language support.
* Light and Dark mode.
* Responsive design for desktop, tablet, and mobile devices.
* Simple and user-friendly interface.
* No account or sign-up required.
* Tools are accessible directly from the main page.

### 📩 Contact

* Built-in contact form for questions, suggestions, and feedback.
* Contact form submissions are handled through Web3Forms.

---

## 🛠️ Tech Stack

### Front-End

* **HTML5** – Used to create the structure and content of the website.
* **CSS3** – Used to create the responsive and modern user interface.
* **JavaScript (Vanilla JS)** – Used for calculations, timers, task management, dynamic content, language switching, and user interactions.

### Additional Technologies

* **LocalStorage** – Used to store selected user preferences and data locally in the browser.
* **Web3Forms** – Used to process contact form submissions.
* **GitHub Pages** – Used for free website hosting and deployment.

## 🔧 How to Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/nada509/student-tools.git
```

### 2. Navigate to the project folder

```bash
cd student-tools
```

### 3. Open the application

Open `index.html` using any modern web browser, such as:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

No installation or build tools are required to run the front-end application locally.
